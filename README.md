# Weather Diary-Дневник погоды

## Автор
Виктор Руданенко

## Описание программы
Weather Diary это desktop-приложение с графическим интерфейсом для ведения личного дневника наблюдений за погодой. Программа позволяет добавлять записи, фильтровать их по дате и температуре, а также сохранять данные в JSON-файл.

## Как запустить
```bash
python weather_diary.py
